# ⚡ QueueLess – Smart Campus Queue Predictor

**QueueLess** is a frontend-based smart campus queue prediction platform designed to help students save time by monitoring crowd levels and estimated waiting times at various campus facilities.

It provides a centralized dashboard to explore campus facilities, check queue status, analyze crowd trends, and discover the best time to visit different locations.

## 🚀 Features

- **Live Queue Dashboard** – View estimated waiting times and queue lengths across campus facilities.
- **Crowd Level Indicators** – Identify low, moderate, and high crowd levels using color-coded indicators.
- **Campus Crowd Heatmap** – Visualize crowd distribution across campus locations.
- **Queue Analytics** – Explore hourly crowd trends and waiting time comparisons.
- **Best Time to Visit** – Discover recommended visiting times to avoid long queues.
- **Queue Intelligence** – Get smart, rule-based recommendations to save time.
- **Interactive Facility Cards** – Explore detailed information about campus facilities.
- **Search & Filters** – Find facilities based on names and crowd levels.
- **Responsive UI** – Optimized for desktop, tablet, and mobile devices.
- **Demo Simulation Mode** – Explore the platform using realistic simulated queue data.

## 📸 Project Overview

QueueLess provides an intuitive dashboard featuring campus facility monitoring, crowd analytics, and intelligent recommendations.

## 💡 Problem Statement

Students frequently waste time standing in queues at campus canteens, photocopy shops, stationery stores, and administrative offices.

QueueLess addresses this problem by providing estimated queue information and recommendations that help students make informed decisions about when and where to visit.

## 🎯 Objective

To improve everyday campus life by reducing unnecessary waiting time and making campus facilities more accessible through a simple, interactive, and technology-driven solution.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/Harshthapar/Queueless.git
```

Navigate to the project directory:

```bash
cd Queueless
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 🏗️ Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## ⚠️ Disclaimer

QueueLess currently operates in Demo Simulation Mode. Queue counts, waiting times, and crowd analytics are generated using sample data and do not represent actual live campus sensor information.
